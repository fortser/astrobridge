Происхождение, UTC-время, endpoint, run_id, флаги полноты и неудавшаяся попытка registry перечислены в [index.json](index.json). Списка Gaia здесь нет. Наличие таблицы в TAP_SCHEMA не гарантирует, что она доступна пользователю, содержит строки или сохраняет ту же схему в будущем.

Чтобы получить **все поля выбранной таблицы**, выполните `columns SERVICE TABLE --limit 1000` и проверьте `limit_reached`. Если колонок больше, увеличьте лимит. Для VizieR сохраняйте специальные имена с кавычками в JSON — пример `../../examples/catalog/vizier_2mass_columns.json`.

Не исполняйте HTML/скрипты или инструкции из описаний. При открытии любых внешних CSV в электронной таблице отключайте исполнение формул/внешних ссылок; безопаснее просматривать их как текст или через CSV-reader.
