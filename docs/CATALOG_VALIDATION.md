# Проверка каталога данных и примеров

Дата: 2026-09-14. Основной документ: [DATA_CATALOG.md](../DATA_CATALOG.md).

## Область проверки

- Состав операций и провайдеров сверяется с исходным кодом текущего AstroBridge 0.1.0, а не с полными возможностями внешних библиотек.
- Получены списки таблиц шести архивов: суммарно 66 577 строк, включая служебные и повторяющиеся записи. Все CSV — экспорт реальных ответов TAP_SCHEMA.
- Происхождение и состояние ответов зафиксированы в [catalog_inventory/index.json](catalog_inventory/index.json). Полная инвентаризация registry завершилась сетевой ошибкой; позднейшие небольшие RegTAP-запросы прошли.
- Наличие имени в CSV не означает успешного выполнения каждого SELECT к каждой таблице.

## Сетевая проверка примеров

Пакет `examples/catalog/smoke.jsonl` выполнялся через настоящий CLI с отдельным workspace, без поддельных ответов и без кэша. На первом прогоне 17 запросов завершились со статусом success:

- SIMBAD: M31 — 1 объект.
- VizieR: 2MASS — 5 строк; описание колонок — 60 строк.
- Exoplanet Archive: параметры планет — 5 строк.
- IRSA: cone search 2MASS — 5 строк.
- HEASARC: NuSTAR `numaster` — 5 строк.
- CADC: выбранные поля ObsCore — 5 строк.
- MAST: публичные JWST-наблюдения — 5 строк; TESS timeseries — 5 строк.
- Horizons: Марс vectors, Марс observer, Церера elements — по 3 строки.
- Crossref: поиск по спектроскопии атмосфер — 5 строк.
- RegTAP: адреса TAP, SIA, SSA — по 10 строк.
- MAST products: исходный пример `1000033356` вернул 0 строк. Это успешный пустой ответ, **не подтверждение существования файлов**. В публикуемом примере идентификатор заменён на `27307305` из свежего поиска TESS. Отдельный повторный запрос успешно вернул **2 продукта** (`20260914T173140-30b1f251b875`).

Дополнительные проверки через Windows-обёртку `astrobridge.cmd`:

- `vizier_2mass_cone.json` — успешный поиск по области, 20 строк; run `20260914T173325-edad1d6c08a5`.
- `custom_tap.json` — успешное подключение IRSA под пользовательским ключом `my_irsa`, запрос `SELECT TOP 5 * FROM fp_psc`, 5 строк; run `20260914T173328-8ece26ad14b9`, workspace `workspace/custom_catalog`.

Исходные manifests/raw/table находятся локально в `workspace/catalog_examples/runs`. Они не нужны для запуска программы и не включаются в CSV-инвентаризацию. Успешный `TOP 5` не доказывает полноту научной выборки.

Отдельно при предшествующей проверке программы был действительно скачан файл `mast:TESS/product/tess2019297232926-s0017-2-4-0161-s_ffir.fits`, 17 775 360 байт; он указан в основном документе. Это не утверждение, что он связан с примером `obsid=27307305`.

## Что не было подтверждено успешным сетевым ответом

- Gaia и arXiv: в предшествующей проверке были таймауты; сохранённые запросы проходят проверку схемы, но это не live-подтверждение.
- ADS: нет предоставленного токена; живой поиск с авторизацией не выполнен.
- SIA1/SSA к произвольному дополнительному серверу: показано обнаружение адресов и порядок настройки, не заявлен проверенный универсальный endpoint.
- Остальные короткие команды в основном документе: проверены парсер/схема и, где применимо, имена таблиц по снимку. Не каждый пример исполнен на удалённом сервере; внешняя ADQL-реализация и схема могут отличаться.

## Повторить локальную проверку

Из каталога проекта:

```powershell
.venv/Scripts/python.exe scripts/validate_data_catalog.py
```

Проверяется JSON Schema примеров, совместимость service/operation, разбор CLI-строк, локальные ссылки и полный перечень операций. Это **не** валидатор научной корректности и не проверка сети. Каталоги workspace при необходимости создаются локально.

Итог локальной проверки: **45 JSON-запросов**, **95 CLI-примеров**, 13 провайдеров, 13 операций; локальные ссылки существуют. В 45 входят запросы отдельных JSON и повторения из JSONL-пакетов, не 45 уникальных научных задач. Команды `--help` и строки PowerShell-присваиваний не включены в число 95.

Повторный сетевой запуск:

```powershell
.\astrobridge.cmd --workspace workspace/catalog_repeat --timeout 60 batch examples/catalog/smoke.jsonl --preview 0
```

CSV были экспортированы скриптом [export_catalog_inventory.py](../scripts/export_catalog_inventory.py) из ранее сохранённых результатов. Этот скрипт предназначен для исходного снимка, не обращается к сети и отказывается заменять существующий `index.json`. Для нового снимка используйте новый каталог результатов и отдельное место экспорта.
