# Проверка AstroBridge 0.1.0

Дата: **2026-09-14**. Окружение: Windows x64, Python 3.10.6. PySide6 6.11.2, Astropy 6.1.7, PyVO 1.9.1, Requests 2.34.2. Полный снимок зависимостей: [requirements-tested-win-py310.txt](../requirements-tested-win-py310.txt).

## Автоматические проверки

Команда: `.venv/Scripts/python.exe -m pytest -q`.

Результат: **33 passed**, без предупреждений в последнем прогоне перед финальной проверкой интерфейса.

Покрыты:

- TAP sync и UWS async через настоящий локальный HTTP-сервер и PyVO;
- отмена выполняющегося UWS-задания с проверкой отправки ABORT;
- сохранение raw-ответов, единиц, UCD, масок и 64-битных идентификаторов без JSON-округления;
- явное усечение VOTable, ошибочные ответы и отсутствие выдуманной таблицы при ошибках;
- экспорт ECSV, CSV, FITS, VOTable, JSON; запрет перезаписи существующего результата;
- TTL/cache reuse, обнаружение изменённого raw-артефакта и повреждённой сохранённой таблицы;
- валидация схемы и nonfinite-координат; отклонение XML entities;
- MAST pagination, Horizons parameters, Crossref nested metadata, arXiv Atom, SIA 1 и SSA;
- HTTP-прокси с Basic authorization, SOCKS5h с передачей DNS-имени прокси;
- отсутствие прямого fallback при сломанном прокси, режим direct, proxy env, Retry-After, redirects;
- отсутствие тестового пароля прокси в сохранённых файлах и JSON-ответах;
- потоковая загрузка, лимит размера, сохранность существующего файла при коллизии имени, защита basename;
- JSON stdout, UTF-8 stdin, JSONL с продолжением после ошибки;
- обязательность явно указанного config-файла;
- GUI-формы, таблица, фильтрация, история и выполнение через QThread с обработкой событий интерфейса.

`pip check`: **No broken requirements found**. `compileall` для `src`: успешно. Проверен Windows CLI launcher `astrobridge.cmd doctor`.

Все 7 JSON-примеров запросов из `examples/` прошли проверку схемы. Собран установочный wheel `dist/astrobridge-0.1.0-py3-none-any.whl`.

## Повторение

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe scripts\live_check.py simbad exoplanet mast
.venv\Scripts\python.exe scripts\check_mast_download.py
```

`check_mast_download.py` использует ранее найденное MAST-наблюдение из `workspace/live`, получает до 30 продуктов и выбирает один файл не более 20 MiB. Он может ничего не скачать, если подходящего продукта нет. Для полноты сначала выполните `live_check.py mast`. Это диагностический сценарий с реальным сетевым трафиком.
